# Treningsplaner

Planfiler som importeres i openGym: **Plan** → menyen øverst til høyre → **Import a plan file**.
Importen legger rutinene til ved siden av det du har, den overskriver ingenting.

## helkropp-garasjen.opengym-plan.json

Helkropp for hjemmegarasjen (manualer 2,5–24 kg, benk, kettlebell 12 og 16 kg, mølle).
Mål: holde styrken, bygge muskler og god form, 2–3 økter i uka. Kjøres som rotasjon A → B.

| Helkropp A | | Helkropp B | |
|---|---|---|---|
| Goblet squat + enarms roing | 4 × 8–12 | Bulgarsk utfall + roing mot skråbenk | 3 × 8–12 / 10–12 |
| Benkpress + rumensk markløft | 3 × 8–12 | Skulderpress + kettlebell-swing | 3 × 8–12 / 15 |
| Sidehev + bicepscurl | 3 × 12–15 / 2 × 10–15 | Skråbenkpress + triceps | 3 × 10–12 / 2 × 10–15 |
| Mølle, rolig jogg sone 2 | 15 min | Mølle, intervaller 6 × 1/1 min | 15 min |

Alle styrkeøvelser bruker double progression: klarer du toppen av rep-intervallet i alle sett,
foreslår appen neste manual. Første økt setter utgangspunktet, så vektene fyller du inn selv.
